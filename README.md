# ZZZ Operation Bagle Playbook

An illustrated guide to Operation Bagle in Zenless Zone Zero, with loadout notes, chest and vault references, blueprint locations, and a step-by-step route for the illustrated map.

Open [the playbook](index.html) to begin. The page uses the companion `index-assets/` directory for its images.

## GitHub Pages

The site is published from the `main` branch root through GitHub Pages. To update it, replace `index.html` and the corresponding files in `index-assets/`, then commit and push the changes.
